# 計測は CPU の参照実装から始め、GPU は必要になってから

まず CPU(Burst)で4指標を実装し、これをテストの正解にする。走らせて 1 時間の予算に収まらないときだけ、同じ式を compute shader に移す。GPU に移すときも CPU に戻すのは集計値だけにする(前身の実装は全粒子を毎フレーム読み戻して 3.1fps に落ちた)。

Considered Options: 最初から GPU(速いがテストと説明が重い。v1 の頂点数なら CPU で間に合う見込み)、GPU で計算して全頂点を読み戻す(前身の失敗)。

Consequences: GPU 版を足すときは CPU 版との一致(誤差 1e-4)をテストにする。
