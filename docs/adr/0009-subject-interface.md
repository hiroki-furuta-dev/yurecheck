# 被検体は ISubject で差し替える

Attach、Reset、Step(dt)、Params を持つ ISubject で被検体を差し替える。比較が目的なので、同じ検査器に順に載せる必要がある。MagicaCloth 2 は MAGICACLOTH2 の記号で任意依存にし、ソースはリポジトリに入れない。

Considered Options: ソルバごとに別のツール(土俵が揃わない)、シーンに置いてあるものを測るだけ(設定の切り替えと無人実行ができない)。

見直す条件: 手動で Step できない被検体が来たとき。その被検体は「エンジンの更新に任せる」モードで動かし、処理時間はフレーム差分で取る。
