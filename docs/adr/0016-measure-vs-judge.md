# 計測(事実)と判定(方針)を分ける

計測は「このフレームでこの頂点が体の内側に何 mm あった」という事実を出し、判定は「それを許すか」という方針(閾値)を当てる。2つを別の型と別の段にする。理由は、事実は誰が測っても同じで、方針は利用者と作品で違うから。閾値の校正(docs/thresholds/calibration.md)は判定だけを変え、計測の CSV は変わらない。

Considered Options: 計測の中で合否まで出す(閾値を変えるたびに再計測が要り、「指標の妥当性」と「閾値」の議論が混ざる。概念が現実を写していないと回避策が積み上がる、という設計の原則に反する)。

Consequences: summary.csv は指標の値だけを持ち、pass と fail_reasons は Judge が thresholds.json から後で付ける。frames.csv を保存しておけば閾値の変更は再計測なしで再判定できる。
