# 距離は SDF、内外の符号は VRM のコライダー

体との距離は、体のメッシュから毎フレーム低解像度(64³)の SDF を焼いて取る。内外の符号は VRM の SpringBone コライダー(球とカプセル)の和で決め、SDF は距離だけに使う。VRoid の体は首や手首で開いている可能性があり、flood fill の符号は開いたメッシュで壊れる(前身の実装で偽陰性)。

Considered Options: コライダーまでの距離だけ(コライダーの無い部位が測れず、被検体がそのコライダーで衝突している以上「貫通ゼロ」が出やすい)、三角形までの距離(BVH を毎フレーム組み直す実装が重い)、一般化巻き数(開いたメッシュに頑健だが問い合わせが重く実装が大きい。v2 の候補)。
