# AI の役割は「環境」と「開発」の2つ。メンテナが書くファイルを持つ

Claude Code は環境の役割(AGENTS.md、.claude/、.github/、tools/、依存、docs/ops/)と開発の役割(Assets、Tests、docs)のどちらかで起動する。違いは settings ファイル2つと AGENTS.md の節だけ。役割は AI を管理せず、ファイルを管理する。開発の役割は環境の範囲を書けず、要望は docs/proposals/ に書く。指標の式、閾値、正規化、符号、更新順はメンテナが書き、AI は読んで提案だけする(hook が止める)。理由は、自分の言葉で説明できる状態を保つため。

Considered Options: 役割を分けない(環境の変更と機能の変更が混ざり、巻き込みが起きる)、補佐を第3の役割にする(どの役割でも補佐が要り構成が増える。代わりに status と WORKFLOW.md を両役割が持つ)、別のエージェント定義や別リポジトリ(入れ子になる)。
