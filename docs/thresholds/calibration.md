# 閾値の目視校正(記録)

指標が目と合うかを先に確かめ、合う指標だけ閾値を決める。メンテナの目で付けた記録。既定値は「メンテナの目で決めた」と readme に書く。利用者は thresholds.json を書き換えてよい。

## 手順

1. 貫通 p99 の値がばらつくように 10〜20 シナリオを選ぶ。
2. 90 秒の録画を見て、各シナリオに印を付ける: 貫通が気になる / 暴れ・ジッタが気になる / 硬い・不自然 / 気にならない。
3. 指標ごとに、印の群と値の並びがどれだけ一致するかを見る。
4. 一致しない指標は定義を直す。一致した指標だけ、群の境界を閾値にする。
