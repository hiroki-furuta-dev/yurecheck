# Yurecheck の言葉

揺れものの設定を、モーション集に対して自動で測り合否を出す道具の文脈。

**揺れもの**:
髪、スカート、リボン、尻尾など、骨格の動きに遅れて揺れる部位。
_Avoid_: セカンダリ、ダイナミクス、クロス(クロスは布だけを指すので使わない)

**被検体(Subject)**:
揺れものを動かすソルバと、その設定の組。VRM SpringBone、MagicaCloth 2、v2 の XPBD。
_Avoid_: ソルバ単体、プラグイン

**シナリオ**:
アバター × モーション × 被検体 × 設定 の1組。ランナーの実行単位。
_Avoid_: テストケース、ジョブ

**揺れもの頂点**:
SpringBone の関節にスキンウェイトを持つ頂点。判定の対象。
_Avoid_: 布頂点、ダイナミック頂点

**体**:
揺れもの頂点を持たないメッシュ。貫通の相手。
_Avoid_: コリジョン、ボディメッシュ

**貫通**:
揺れもの頂点が体の内側に入ること。深さは体の SDF の負の距離。
_Avoid_: めり込み、クリッピング

**発散**:
NaN、速度の上限超え、包囲箱の膨張のいずれか。
_Avoid_: 爆発、暴走

**ジッタ**:
静止区間での揺れもの頂点の細かな振動。速度の符号反転の回数で測る。
_Avoid_: ノイズ、ブレ

**固定ステップ**:
Time.captureDeltaTime で deltaTime を定数にした進行。決定性の前提。
_Avoid_: 固定 FPS

**ランナー**:
シナリオ一覧を受け取り、無人で回して CSV と報告を出すビルド。
_Avoid_: テストランナー、ハーネス

**段階**:
作業がどこまで進んだかの7つの状態(0 着手前 〜 6 merge 可)。status が判定する。
_Avoid_: ステータス、フェーズ

**閾値**:
合否の境界。メンテナの目視校正から出した既定値を利用者が書き換える。
_Avoid_: 基準値、許容値
